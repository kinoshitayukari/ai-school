技術スタックと基盤構成

プロジェクトは Next.js 14 を中心に、React 18、Framer Motion、Lucide Icons、Tailwind CSS などで構成され、開発・ビルド・Lint 用のスクリプトが package.json に定義されています。

全ページは app/layout.tsx のルートレイアウトを介して配信され、共通の <html lang="ja"> 構造と globals.css で定義されたカラーパレットやベーススタイルが適用されます。

主要ページ

トップページ（app/page.tsx）

  • ヘッダーはスクロール固定のナビゲーションを持ち、CTA ボタンからセクション内リンクや記事一覧への導線を提供します。
  • ヒーローセクションは Framer Motion を用いたアニメーションと、学習価値を訴求するバッジ／ワークフロー紹介カードで構成されています。
  • 「特徴」「プログラム」「活用シナリオ」「料金プラン」「カリキュラム」など複数のセクションがカード UI で整理され、各コースの内容や提供価値を箇条書きで説明します。
  • 講師紹介、ウェビナー申込フォーム、ロードマップ・KPI・FAQ といった信頼性や実装計画を補完するコンテンツが続き、最後に利用規約等へのフッターリンクが配置されています。

記事一覧ページ（app/articles/page.tsx）

  • Node.js ランタイムで public/articles ディレクトリを走査し、HTML ファイルから <h1> タグを抜き出してタイトル化、対応する画像フォルダからサムネイルを探索する静的記事リストを生成します。
  • 取得した記事はカード型リンクとして 2 カラムで描画され、存在しない場合は空状態メッセージが表示されます。

UI コンポーネント

components/ui/button.tsx は CVA を使ったバリアント指定と Slot 経由のラップに対応したボタンコンポーネントを提供します。

components/ui/card.tsx はカード本体・ヘッダー・タイトル・コンテンツのラッパーを定義し、セクション全体で統一感あるカードレイアウトを実現します。

components/ui/input.tsx と components/ui/textarea.tsx はフォーム入力の共通スタイルをカプセル化し、申し込みフォームなどで再利用されています。

ユーティリティ

lib/utils.ts の cn 関数は clsx と tailwind-merge を組み合わせてクラス名をマージし、各 UI コンポーネントでクリーンな Tailwind クラス構成を支援します。
